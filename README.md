# 💰 Kaun Banega Crorepati (Millionaire Game)

A Python-based quiz game inspired by **Kaun Banega Crorepati (KBC)**, where players answer multiple-choice questions to win virtual prize money.

## 📌 Features

- Interactive command-line quiz game
- Multiple-choice questions (A, B, C, D)
- Score and prize money tracking
- Displays correct and incorrect answers
- Simple and beginner-friendly Python project

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/millionaire-game.git
```

2. Navigate to the project folder

```bash
cd millionaire-game
```

3. Run the program

```bash
python main.py
```

## 🎮 How to Play

- The game displays one question at a time.
- Choose the correct option (A, B, C, or D).
- Each correct answer increases your prize money.
- The game ends when you answer incorrectly or complete all questions.
